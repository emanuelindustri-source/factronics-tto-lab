# Resultado · v1.3.0 (2026-10-30)

## Resumen

Se cerraron los hallazgos P1/P2 de la auditoría de 1.2.0, se añadieron pruebas
automáticas y se publicó una APK 1.3.0 con icono adaptativo y mejoras de
navegación. La base de contenido (328 preguntas, 304 enunciados únicos) no se
alteró.

## Cambios realizados

### Página principal

- Enlace “Saltar al contenido”, foco visible y etiquetas ARIA traducidas.
- Resumen dinámico: **328 variantes · 304 enunciados únicos**.
- Enlace de verificación SHA-256 del APK y guía de instalación PWA Android/iOS.
- Tamaño real del APK (~158 KB) y textos de cálculos corregidos.
- Nueva banda de novedades 1.3.
- Versión visible en el pie.

### Generador

- **Comprobar** explícito en Estudio para multi, completar y cálculo. Ya no se
  revela la respuesta al primer clic o carácter.
- Botón de comprobación habilitado solo al responder; el feedback se retira al
  cambiar la respuesta.
- Cantidad 5–100 y duración 0–180 personalizadas, con presets.
- Biblioteca: búsqueda en opciones/respuestas y paginación de 60 en 60.
- Crédito parcial fijado al iniciar el examen.
- Confirmación visible al copiar el resumen; constancia con “código de
  referencia” y prefijo `REF-`.
- Guardado síncrono en `beforeunload`/`pagehide`.
- Validación de cantidad/duración en URL y enlace compartido con `lang`.

### Android

- 1.3.0 (`versionCode 4`), icono adaptativo.
- Estudio con **Comprobar** también en Android.
- “Atrás” en resultados vuelve a configuración; en examen permite finalizar,
  seguir respondiendo o **guardar y salir**.
- Cantidad/duración personalizadas con diálogo Cancelar/OK.
- Biblioteca con “Mostrar más” y contador `visibles/total`.
- Chips de modelo en desplazamiento horizontal (ya no se comprimen con fuente
  grande).
- Versión visible al pie; `adjustResize` para teclado.
- Build: detección de plataforma, `d8` portable, validación de assets, hash
  automático y soporte de keystore por variables de entorno.

### Pruebas y documentación

- `tools/verify.py`: 6.861 comprobaciones, resultado **OK**.
- `tools/export_ui.js` con modo `--check`.
- `tools/export_ui.js` mantiene `ui.json` sincronizado.
- `VERSION`, `CHANGELOG.md`, `QA.md` actualizado y `docs/notas/` histórico.
- `README.md`, `android/README.md`, `tools/README.md` y `download/README.md`
  actualizados.

## Notas de publicación

- El APK se firmó con una clave de entrenamiento nueva. Android puede rechazar
  la actualización desde 1.2.0; desinstalar e instalar, exportando/importando el
  progreso.
- El token de GitHub usado para publicar debe rotarse después de la subida.
- El release `v1.3.0` y GitHub Pages se actualizan con
  `python tools/publish_github.py`.
