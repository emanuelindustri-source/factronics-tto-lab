# Plan · v1.9.0 (2026-11-04)

## Objetivo

Mejorar la verificación con escaneo real desde el navegador, ampliar el banco
con la revisión de fuentes y dejar CI automática.

## Alcance

1. Escáner en `verificar/`:
   - Cámara (`getUserMedia`) con `BarcodeDetector`.
   - Respaldo jsQR para navegadores sin la API.
   - Carga de imagen y arrastrar/soltar.
   - Validación estricta de URL de Factronics.
2. Fuentes y banco:
   - Revisar grados APR/AXR, cabezales, despegue y beneficios.
   - Añadir seis preguntas; el borrador de 100 preguntas ya está representado.
3. CI:
   - Workflow de GitHub Actions para verificación y sincronía de i18n.
4. Landing y textos:
   - Mención del escaneo con cámara y novedades 1.9.
5. Versión, documentación, pruebas y publicación.

## Criterios de aceptación

- Subir el PNG del certificado abre `verificar/` con el resultado.
- El QR del certificado se decodifica con jsQR.
- La cámara se detiene al cerrar o al salir de la página.
- El banco queda en 372/348.
- El workflow de CI existe y ejecuta las dos comprobaciones.
- `tools/verify.py` pasa.
