# Versión 1.6.0 · 2026-10-30

> Ficha legible de la entrega. No se elimina en versiones posteriores.

## Qué incluye

- **Resultado con QR:** al terminar examen o estudio se genera una tarjeta PNG y
  un QR que abre el resultado en el navegador.
- **Datos del técnico:** nombre, apellido, correo, puntaje, fecha, equipos y
  desglose por tipo.
- **Página de resultado:** `resultado/?d=…` muestra el informe escaneado y
  comprueba un checksum FNV-1a para detectar alteraciones accidentales.
- **Informe PDF con QR:** el PDF A4 incluye el mismo QR y el código de referencia.
- **Compartir sin correo:** PDF y PNG se comparten con la hoja del sistema
  (WhatsApp, Drive, archivos, etc.). No se envían datos a servidores.
- **Se mantiene:** identificación, partículas, animaciones, 350 preguntas / 326
  enunciados únicos y avisos de actualización web/Android.

## Cómo usarlo

1. Escribe nombre, apellido y correo.
2. Realiza el examen o el estudio y pulsa **Finalizar**.
3. Pulsa **Tarjeta QR** para descargar un PNG con el QR, o **Informe PDF** para
   el informe A4.
4. Escanea el QR con el teléfono: abre el resultado en el navegador.
5. Comparte el PNG/PDF con quien necesites; no hay envío automático por correo.

## Limitaciones

- El checksum no es una firma criptográfica; para autenticidad formal hace falta
  un backend o una firma con clave privada.
- El QR abre una página de GitHub Pages; requiere conexión al escanearlo.
- Android no instala actualizaciones en silencio: abre la descarga.
- La clave del APK es de entrenamiento, no de producción.
